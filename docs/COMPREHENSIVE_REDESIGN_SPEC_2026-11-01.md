## 1. 总目标与设计原则

### 1.1 总目标

把当前“有界面、有承诺、但缺完整玩法链”的系统，补成**玩家能玩、资源能循环、失败有兜底、展示与结算一致**的完整模块；核心身份向原作对齐，但保留单机版的节奏与结构，不引入联机内容。

### 1.2 六件套标准

任何系统必须同时具备：

1. **入口**：玩家在哪里看到、怎么开始
2. **产出**：资源/道具从哪里稳定获得
3. **消耗**：用在哪里、消耗多少、节奏
4. **恢复/补充**：用完怎么补、有没有兜底
5. **反馈**：界面真实反映效果
6. **失败兜底**：资源断供后仍能继续玩，不锁死

### 1.3 设计原则

1. **展示=生效**：界面显示的数值/词条必须进入实际计算；不生效就不显示。
2. **不做“半套”**：要么做成完整闭环，要么从界面降级/删除，不保留“看起来有”的空壳。
3. **单机优先**：不引入 PVP、联盟、国战、排行、交易、真人掠夺；原作中这些内容只作为背景资料，不落地。
4. **旧档兼容**：旧 ID 在读取层归一；新增字段给默认值；不批量改存档；不追溯扣资源。
5. **小步可回滚**：按 L1→L2→L3→L4 分层，每层独立提交、独立验证。
6. **核心身份向原作对齐**：背景、职业、宠物 22 种、副本七门、古堡 100 层、300 秒等保留；原作有完整设计且成本可控的（宠物体力、真武、孔位、首饰耐久、熔炼、夜煞龙）优先对齐。

## 3. 设计基线（路线 C：综合）

### 3.1 向原作对齐（参考原作）

- 宠物体力：采用 **2014 新手FAQ 三阈值**（<80 天赋技能无效；<60 附加属性减半；<40 附加属性无效）+ **每日固定-10** + **死亡-5**
- 转职：补第 8 阶 **真武（90 级，12000 声望）**
- 装备：孔位改为 **武器3 / 防具2 / 首饰1**；**项链、戒指无耐久**
- 熔炼：补 **4 件同套装 → 1 件指定部位**（并消耗对应品质晶石）
- 屠龙：补 **夜煞龙** 与 **光明圣使套装**
- 宠物特性：原作“黄金无特性、暗金+才有”，本作保留黄金特性但明确标注为单机增强

### 3.2 保留我们的（单机改编）

- 1 个王都 + 5 张地图（不扩 16 图）
- 26 章主线（不压回 12 地区）
- 3 条龙的**真实战斗**（不做 5000 次木桩刷）
- 套装 **2/4 件** 结构
- 野外地图**巡逻挂机**（不做训练场双模式）
- 佣兵/侍从/钓鱼/阵营/晶石/圣遗物/符文/魔典等自创系统（按内部闭环修）
- 每日委托/酒馆悬赏（不做 20 次赏金墙）

### 3.3 统一口径

- 所有“100%还原”“完全还原”类文案改为“单机改编/精简版”
- 原作没有的字段不伪造（如独立“破击率”，除非按 D7 选择补完整系统）
- 红框联机内容一律不引用、不落地

### 3.4 行动日（Action Day）时间体系（2026-11-01 追加）

> 用户要求：游戏内“天数”不再跟现实时间走，而按玩家完成的动作次数推进；所有与时间相关的设定都要重新设计，避免挂机/现实时间造成非正常成长。**本轮只实现逻辑，UI 改动不实施，仅记录。**

#### 3.4.1 定义

- **1 行动日 = 30 行动点（AP）**（默认，可调）。
- 只有**有效战斗胜利**与少量关键行为产生 AP；打开界面、购买、强化、喂养、钓鱼、交易等不产生 AP。
- AP 达到 30 → `day + 1`，剩余 AP 保留，触发“新的一天”重置。
- 每次动作最多推进 1 天；不会因为一次大额奖励跳多天。
- 不登录、不战斗时，**游戏天数不前进**，也不产生任何现实时间收益。

#### 3.4.2 行动点来源

| 行为 | AP |
|---|---|
| 野外普通战斗胜利 | +1 |
| 野外首领战胜利 | +3 |
| 古堡/魔塔每层胜利 | +1 |
| 副本每层胜利 | +2 |
| 屠龙战斗胜利 | +3 |
| 竞技场挑战胜利 | +1 |
| 悬赏目标战斗胜利 | +2 |
| 幻境试炼胜利 | +3 |
| 要塞攻克胜利 | +3 |
| 失败/逃跑/撤退 | +0 |
| 喂养、购买、强化、熔炼、钓鱼、领奖、开界面 | +0 |

#### 3.4.3 新一天触发的内容（统一重置）

| 项目 | 原现实时间逻辑 | 新行动日逻辑 |
|---|---|---|
| 古堡次数 | 每日 3 次（按系统日期） | 每行动日 3 次 |
| 副本次数 | 每日 5 次 | 每行动日 5 次 |
| 屠龙次数 | 每日 3 次 | 每行动日 4 次（含夜煞龙，见 §4.5） |
| 竞技场次数 | 每日 5 次 | 每行动日 5 次 |
| 酒馆悬赏 | 每日刷新 | 每行动日刷新 |
| 酒馆饮品 Buff | 现实“整日” | 到下一行动日为止 |
| 每日俸禄 | 按现实日期 | 每行动日 1 次 |
| 阵营军饷 | 按现实日期 | 每行动日 1 次 |
| 要塞重复奖励 | 现实日期 | 每行动日每要塞 1 次 |
| 宠物体力 | 现实每日 -10（本次新增规则） | 每行动日 -10 |
| 庄园药园/矿脉 | 30 分钟/批，最多 20 批 | 每行动日最多 2 批：累计 10 AP 成熟 1 批、20 AP 成熟第 2 批；不按现实时间 |
| 巡逻挂机 | 按现实分钟无限累积（上限 600 分钟） | **取消现实时间累积**；每行动日最多领取 1 次，收益按“10 分钟”基准计算（见下） |
| 侍从采矿/惩戒 | 30 分钟冷却 | 每行动日各 1 次（UI 联动放 L3） |
| 侍从安抚/整备 | 2 小时 | 持续 1 个行动日（L3 改造时落地） |
| 钓鱼兑换 | 无日限 | 每行动日兑换上限（L3 落地） |

#### 3.4.4 挂机/巡逻收益削减

- 原：`getIdleRewards` 按现实分钟累积，最多 600 分钟，收益 = 分钟 × 每分产出。
- 新：**每行动日 1 次**，固定按 **10 分钟** 的当前地图产出结算。
- 即原来挂机 10 小时可拿 600 分钟收益，现在最多 10 分钟/行动日；**约砍到原来的 1/60**（针对满挂机），避免离线膨胀。
- 巡逻仍保留地图分级：高级地图的 10 分钟收益更高，鼓励推进而不是挂低级图。
- `setPatrolMap` 转营地时，若当日未领取，先结算旧营地；已领取则不再产生。

#### 3.4.5 防止非正常成长

1. 现实时间**不再产生任何收益**（巡逻、庄园、侍从冷却全部改为行动日/AP）。
2. 每日重置只能由 AP 推进触发，不能通过改系统时间、刷新页面重复触发。
3. 低价值重复动作（开界面、买卖、强化）不计 AP，避免刷日。
4. 每日次数、俸禄、悬赏、宠物衰减都集中在“新一天”一次执行，避免多次结算。
5. 挂机收益封顶 10 分钟/日；庄园封顶 2 批/日；钓鱼兑换设日限。
6. 旧档不会因迁移获得额外天数或额外收益。

#### 3.4.6 实施状态（2026-11-01）

- **已实现核心逻辑**：`js/core/actionClock.js`（30 AP/日、行动点常量）；`state.js` 的 `actionClock`、`getActionDay/getActionPoints/addActionPoints`、`resetDailyActivities`、`canClaimSalary/claimSalary`、`getIdleRewards/claimIdleRewards/setPatrolMap`、`harvestEstate`。

- **未实施**：宠物每日 -10（与 §4.1 宠物体力三阈值一起做）；所有 UI 文案/入口/布局（按用户要求本轮不改 UI）。

## 4. 逐系统详细设计

### 4.1 宠物体力与食品（核心，必改）

#### 4.1.1 设计目标

让“体力”成为玩家能看懂、能管理、有恢复手段的养成资源，而不是“打几场就废”的惩罚。

#### 4.1.2 为什么

- 原作 2014 FAQ 有完整三阈值+每日衰减+死亡惩罚，当前实现只取了“<60 全停”并叠加每战扣体力，比原作更严且不可持续。
- 当前没有稳定恢复：兽肉只来自每日一星悬赏/野外10胜/一次性任务；副本不产；金币买不到。玩家断粮后会陷入“越打越弱、越弱越打不动”。
- 宠物没有独立 HP，体力是唯一养成资源，必须可循环。

#### 4.1.3 规则设计

| 体力区间 | 属性加成 | 特性/天赋 | 魔典技能 | 经验 |
|---|---|---|---|---|
| 80–100 | 100% | 生效 | 生效 | 正常 |
| 60–79 | 50% | **失效** | 失效 | 正常 |
| 40–59 | 50% | 失效 | 失效 | 正常 |
| 0–39 | **0%** | 失效 | 失效 | 正常 |

- **每日衰减**：每日 0 点（每日重置）所有已拥有宠物 -10；系统日志提示“宠物每日体力 -10”。
- **死亡惩罚**：战斗失败时，出战宠物（主宠+副宠）各 -5；胜利不扣。
- **取消每战 -3/-1**（替换为每日衰减+死亡惩罚）。
- **恢复**：
  - 魔能兽肉排 +35（现有）
  - 普通宠物口粮 +15（新增）
  - 豪华宠物饼干 +60（新增）
  - 兽栏金币喂养：10 金币/点，最多恢复到 60（单机兜底，防止断粮锁死）
- **经验**：不再受体力影响（宠物仍随队出战，经验正常；主宠全额、副宠一半）。
- **训练**：营地训练仍要求体力≥60（保留现有门槛）。

#### 4.1.4 UI 设计

- **神兽页详情**：体力条改为 4 段色带（绿 80+ / 黄 60–79 / 橙 40–59 / 红 <40），刻度标 40/60/80；状态文字“良好 / 天赋失效 / 属性减半 / 属性无效”。
- **神兽列表卡片**：右上角小体力徽标（颜色+数字）。
- **战斗页伙伴槽**：沿用现有四格，状态文字改为“体力 72 · 天赋失效 / 体力 55 · 属性减半 / 体力 30 · 属性无效”，并保留体力条。
- **兽栏页（新增）**：王都设施目录新增“皇家兽栏”，列表显示全部宠物、体力、状态、喂食按钮（兽肉/口粮/饼干）、金币喂养（最多到60）。
- **每日提示**：上线系统日志/公告“今日宠物体力 -10，请到兽栏查看”。

#### 4.1.5 操作流程

1. 上线 → 系统日志提示每日 -10
2. 打开“神兽”或“王都→皇家兽栏”
3. 查看体力条与状态（80/60/40 刻度）
4. 选择宠物 → 喂食（兽肉/口粮/饼干）或金币恢复到 60
5. 出战 → 战斗失败时出战宠物 -5
6. 次日 0 点再次 -10 → 循环

#### 4.1.6 落地改哪里

- `js/core/petParty.js`：`getPetParty` 返回 `traitActive`（≥80）、`attributeMultiplier`（80+ =1、60–79=0.5、<60=0.5? 按表 0–39=0；即 40–79=0.5、<40=0）、`expActive`（始终 true）

#### 4.3.2 首饰无耐久（建议改）

- **改哪里**：`items.generateEquipment`、`state.completeBattle`、`state.getEquipmentRepairCost/repairAllEquipment`、`bagView` 显示。

#### 4.3.3 熔炼店（建议补，L3）

- 原作：装备大厅熔炼店，4 件套装合成 1 件（随机出所使用套装部件以外的部件），可直接熔炼指定部位。
- **设计**：铁匠铺新增“熔炼”页签：
  - 选择 4 件同套装、同品质的套装部件
  - 选择目标部位（不能在已消耗的 4 件中）
  - 消耗 1 颗对应品质晶石（黄金晶石/暗金晶石/紫金晶石）
  - 产出 1 件该套装、目标部位的装备（等级=套装等级，品质=套装品质，随机词条可选）
- **目的**：消耗冗余套装、解决紫金晶石死端、接近原作熔炼。
- **改哪里**：`townView` 新增 `smithy_smelt_set` 子页/页签；`state` 新增 `smeltSetPieces(uidList, targetSlot)`；`items` 新增套装部件生成 helper（复用 `generateEquipment` + `setId`）。
- **UI**：四格材料槽 + 目标部位下拉 + 晶石槽 + 产出预览 + 确认。

#### 4.3.4 洗炼/清除（不改，改文案）

- 原作：洗炼水晶重置蓝+品质附加属性；清除水晶清除单颗宝石属性。
- 当前：重铸词条、免费摘除宝石，已覆盖类似需求。
- **设计**：保留现有；删除“洗炼水晶/清除水晶”道具文案；在重铸页说明“本作以重铸替代洗炼”。

#### 4.3.5 装备命中（必改）

- 现状：`items.generateEquipment` 随机生成 `stats.hit`，行囊显示“命中 +N%”，但 `getEffectiveStats` 装备分支未累加 hit；实测装备 hit+44 后有效命中仍 95。
- **设计**：`getEffectiveStats` 装备分支补 `hit += item.stats.hit`；同时把显示改为“命中值 +N”（非百分比）；人物页“精准命中”改为“命中值”。
- **平衡**：补命中会让高等级武器命中溢出（99 上限），需同步下调装备 hit 数值或给命中值设软上限；跑战斗回归。
- **改哪里**：`state.getEffectiveStats`、`items.generateEquipment`（数值）、`bagView`（STAT_NAMES/PERCENT_STATS）、`heroView`（文案）。
- **验收**：装备 hit+N 后有效 hit 增加；行囊/人物/战斗三处一致。

#### 4.3.6 破击（不改，保留破甲并标注）

- 原作有独立“破击值/破击率/破击伤害”，我们引擎没有完整系统，只有 `armorBreak` 固定护甲削减。
- **建议**：不伪造“破击率”；把现有 `armorBreak` 显示为“破甲”；在文档/图鉴标注“本作未实现原作破击系统”。若未来要做，按 L4 单独立项。

## 6. 核心操作流程（端到端）

### 6.1 宠物每日维护

```
上线
→ 系统日志“宠物每日体力 -10”
→ 神兽页 / 王都→皇家兽栏
→ 查看体力条（80/60/40 刻度）与状态
→ 选择宠物：喂兽肉(+35) / 口粮(+15) / 饼干(+60) / 金币喂养(最多60)
→ 出战
→ 战斗失败：出战宠物 -5
→ 次日 0 点：再次 -10
```

反馈：体力条实时变化、状态文字、系统日志；断粮时金币喂养兜底。

### 6.2 装备熔炼

```
王都→铁匠铺→熔炼
→ 选择 4 件同套装同品质部件
→ 选择目标部位（不在已选 4 件内）
→ 选择对应品质晶石
→ 预览产出（套装/部位/等级/品质）
→ 确认 → 扣除材料 → 产出装备
```

反馈：材料不足置灰、产出预览、结果弹窗；旧档超孔装备只读提示。

### 6.3 副本三模式

```
魔塔→副本→选门
→ 选择阵型：单枪 / 佣兵援护 / 侍从出战
→ 校验（未雇佣/无侍从则禁用并提示）
→ 进入战斗 → 战场实际阵容与选择一致
→ 胜利/失败 → 继续或撤离
```

### 6.4 屠龙

```
王都→屠龙殿
→ 选择红/银/金/夜煞
→ 确认次数与消耗
→ 真实战斗（会受伤）
→ 胜利：套装/材料/蛋/食品
→ 失败：消耗次数、无奖励
```

### 6.5 转职

```
王宫→幻境试炼
→ 查看 8 阶（魔/幻/影/皇家/圣/神/绝地/真武）
→ 达到等级+声望 → 挑战
→ 胜利 → 称号+属性
```

### 6.6 战斗页

```
进入战斗（野外/魔塔/副本/屠龙/竞技）
→ 顶部横幅：场景 + 出战阵容四格
→ 左右：大肖像 + 生命/魔力 + 开场属性
→ 中央：战报（伤害红/技能蓝/治疗绿）
→ 底部：1x/3x/跳过 → 结算 → 战利品入战报 → 领取
```

## 7. 数据模型与存档兼容

### 7.1 新增/调整字段

| 字段 | 用途 | 兼容策略 |
|---|---|---|
| `data.petStaminaDate` | 每日体力衰减日期 | 缺省为今日，首次登录不追溯 |
| `data.petExpBuff` | 女神祝福（可选） | 缺省 null |
| `data.factionWar.strongholds[id].lastClearDate` | 要塞重复奖励日限 | 缺省 null |
| `data.slaves.list[i].uid` | 侍从唯一标识 | 旧档无 uid 时用 `slave_<id>_<index>` 生成 |
| `data.fishing.lamprey/arowana` | 鱼获计数（已有） | 保留 |
| `data.dungeon.companionMode` | 副本阵型 | 缺省 'none' |
| 装备 `durability`（项链/戒指） | 改为无耐久 | 旧档读取时删除该字段或忽略 |

### 7.2 迁移原则

1. 旧 ID 归一：`crystal_protect`→`protect_crystal`（发放时也归一）。
2. 旧档体力保留，不追溯每日衰减。
3. 旧档超孔装备保留孔数、禁止继续开孔。
4. 旧档侍从无 uid 时生成稳定 uid；重复 id 允许存在但操作按 uid。
5. 新增 `data.schemaVersion`（可选）用于未来迁移。

## 10. 风险与回滚

| 风险 | 影响 | 缓解 |

| 宠物体力重做导致旧档变强/变弱 | 战斗平衡 | 先跑基线；旧档不追溯；保留开关/版本 |
